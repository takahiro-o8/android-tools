# 全アプリ共通の開発原則

## 設定変更で古い設定・データを残さない(オーナー指示)
設定を変えたのに前の設定やデータが残って反映されない不具合を、仕組みで防ぎます。

- 画面はモデル(保存データ)から毎回まるごと作り直す。部分更新で整合性を保とうとしない
- 設定画面は呼び出し元ごとにまっさらに開く(`FLAG_ACTIVITY_NEW_TASK | FLAG_ACTIVITY_CLEAR_TASK`、専用の `taskAffinity`、`onNewIntent` で作り直す)。既存タスクの使い回しで別対象の画面が出ないように
- 設定を保存したら、表示に関わるデータ(キャッシュ・取得結果)は必ず取り直す・作り直す
- 時間のかかる取得は、完了時に設定が変わっていないか確認し、古い設定で取った結果は保存しない
- 設定画面には「どこに保存されるか」を明示する

## 配布
- APK を GitHub Releases で配布し、上書き更新できるようにする(同じ署名鍵・versionCode は単調増加)
- 署名鍵は GitHub Secrets。鍵のエイリアスをアプリごとに決め、CI はそのエイリアスを含む鍵だけを本番鍵とみなす(別の鍵での誤署名を防ぐ)

## 依存を減らす
- アプリが許す限り外部ライブラリを使わない。E2E も Python 標準ライブラリと adb だけで書く(壊れにくく、どの AI でも読める)
