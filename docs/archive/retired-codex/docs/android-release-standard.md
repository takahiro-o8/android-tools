# Androidアプリ共通の署名・配布基準（準備案）

## 目的
同じアプリの更新で同じ署名を維持し、APKをGitHubアプリから直接取得できるようにする。対象はAI Usage、File、Traffic Monitor、Voice Copyと、今後のAndroidアプリ。

## 共通ルール
1. アプリIDは既存値を維持する。配布するversionCodeは既存配布済みの最大値より大きくする。並行ビルドや再実行で番号が逆転しないよう、配布は直列化し、公開直前に既存APKと照合する。versionNameとAPKファイル名 `アプリ名-バージョン.apk` を一致させる。
2. アプリごとに既存の固定署名鍵を維持する。全アプリを同一鍵に変更しない。鍵とパスワードはGitに入れず、安全なバックアップを保管する。
3. 固定鍵が未設定・一部欠落・不一致なら配布を中止する。既存Secretsを推測や自動再生成で上書きしない。旧署名鍵が存在する場合は新規鍵を作る前にその鍵を確認する。
4. 公開前にAPKのアプリID、versionCode、versionName、署名のSHA-256証明書を確認する。固定鍵が導入済みなら、証明書をそのアプリの既存配布APKと照合する。一時鍵ファイルは削除する。
5. 自動テスト、lint、APKビルドの成功後にGitHub ReleasesへAPKを添付する。公開URLは該当Releaseページとし、GitHubアプリのAssetsからAPKを選ぶ案内を行う。
6. 鍵が変わる初回の移行では、旧版から上書きできないことと、アンインストールでアプリ内データが消えることを公開前に明記する。初回移行後は同じ鍵を維持し、データを消さず更新できる形を目指す。
7. 実機での更新インストールを確認した場合のみ、実機確認済みと記載する。APKの署名照合と実機インストールは別の検証。

## 調査結果と作業

| アプリ | 確認できた状態 | 変更準備 |
| --- | --- | --- |
| AI Usage | 固定鍵Secretsを使い未設定なら配布を停止。過去の固定鍵版あり。Actions実行番号をversionCodeに利用。 | 使用中の鍵と既存配布署名を維持。配布順・版名の整合性を確認。現状はRelease一覧に0.6.6、0.6.8、0.6.7などが混在するため、単純な最新一覧順で最大版を決めない。 |
| File | 固定鍵と既存APKの証明書照合を記録。配布履歴は0.8.0まで確認。 | 同じ鍵を維持。公開履歴と署名照合を引き続き必須化。 |
| Traffic Monitor | 確認できたGitHub Releaseは0.1.0のみでデバッグ署名。固定鍵の有無は未確認。 | 既存の固定鍵・配布物の有無を確認後、なければ新規鍵を設定。移行時はデータ消去を案内。 |
| Voice Copy | 現行Releaseはビルドごとにデバッグ署名。新しい固定鍵と署名スクリプトをローカルに準備済みだが、Secrets登録・署名APK検証は未完了。 | 固定鍵と証明書を安全にバックアップし、Secretsを既存状態確認後に登録。固定署名APKの検証と配布を行う。旧版からは一度だけ再インストールが必要。 |

## 2026-10-27 適用状況

- File: 既存署名の検証、既存Releaseの差し替え防止、過去のdist APKより大きいversionCodeの検査をmainに適用し、Actionsで検証済み。
- AI Usage: 既存配布版の署名証明書との照合、配布の直列化、過去の署名済みReleaseの実行番号に基づくversionCode逆行防止をmainへ適用。固定鍵署名とRelease公開に成功した。
- Voice Copy / Traffic Monitor: 固定鍵を必須にし、証明書とAPK情報を検証する変更をmainへ適用。鍵は本人がGitHubのSecrets画面から登録し、鍵とパスワードのバックアップを安全に保管する。ユーザーの指定により、MacへのCLIや追加ソフトのインストールは前提にしない。既存の署名関連Secretsがある場合は停止する。固定署名版へ移行する際、旧デバッグ版から一度再インストールが必要。
- 固定署名APKの実機での上書き更新は未検証。

## 未完了・確認事項
- GitHub接続はActions Secretsの書き込みを提供せず、環境のGitHub CLI認証も現在無効。鍵をチャットに送らず、書き込み権限のある認証経路でセットアップする。
- 準備済みのVoice Copy・Traffic Monitorの鍵のバックアップとSecretsの状態を、登録・公開前に確認する。既存の固定署名が見つかれば、その鍵との互換性を優先する。
- 現在この文書は基準の準備であり、全アプリの署名固定、リリースや実機更新の検証は完了していない。
