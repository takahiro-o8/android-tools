# 全アプリ共通：ウィジェットとフォント

2026-11-03のユーザー指示。既存アプリと今後作成するアプリの両方に適用する。
正本: https://github.com/takahiro-o8/android-tools/blob/main/docs/WIDGET_STYLE.md

## ウィジェット

- 背景は常に完全透明。カード色・背景色・背景の透過度の選択肢は設けない。
- Androidシステムのライトモードでは不透明な黒文字（#000000）。
- Androidシステムのダークモードでは不透明な白文字（#FFFFFF）。白文字にはPixelホーム画面に近い細い暗色の縁取り／標準TextViewの影を付ける。
- 文字色を壁紙の代表色、明るさ、アプリ独自の背景設定で切り替えない。
- すでに配置済みのウィジェットにも適用する。旧背景設定は新描画で参照しない。モード変更時は取得済みデータで描き直し、通信量や使用量を新たに取得することを条件にしない。
- 使用量の意味を表すゲージ色やデータは各アプリの仕様を維持する。

## フォント（全アプリのUI）

- Pixel搭載のシステムGoogle Sans（フォントファミリー google-sans）を優先する。
- 未搭載端末ではAndroidの標準sans-serifへフォールバックする。別の独自フォントを同梱しない。
- 通常・太字は同じフォントファミリーのウェイトを使う。設定画面、ボタン、ウィジェットで統一する。
- PDF・画像・閲覧対象ファイルなど、ユーザーのコンテンツ自体の書体は変更しない。

## 実装と引き継ぎ

各リポジトリのAGENTS.md／CLAUDE.mdからこの共通仕様を参照する。アプリ固有の過去の配色・背景指示より、今回の仕様を優先する。設定・データ・署名鍵・アプリIDは維持し、配布時のversionCodeは増加させる。新しいアプリも同じ仕様から始める。
