# 判断の記録（現行方針）

## 2026-11-16 GitHub Actionsのリソース節約
- E2E/エミュレーターの実行・仕組み・手順書は全面撤去し、Git履歴以外には残さない。
- 既存アプリは現在の署名鍵を変更せず、mainのアプリ修正で署名済み正式APKだけを公開する。
- 新規アプリもE2Eテンプレートを持たず、署名・版数・APK検証の最小構成とする。

## 2026-11-03 全アプリのウィジェットと書体
ウィジェットは透明背景・システムのライト=黒文字／ダーク=縁取り付き白文字・Pixel標準フォントを共通とする。正本はWIDGET_STYLE.md。

## 2026-11-16: 正式バージョンをx.y.zに統一

ユーザーの最新指示でビルド番号の接尾辞を廃止。公開済みAPKの検証済み履歴を元に3整数で比較し、パッチを自動更新する。内部versionCodeもGitHubの実行番号から独立させる。既存6アプリの基盤SHAを更新し、今回だけCIをスキップして次回の通常ビルドから適用。[VERSIONING.md](VERSIONING.md)を正本とする。

## 2026-11-20: 全アプリで明示的GOまで開発しない

オーナーが「ゴーサインだすまで開発しないで。これはどのアプリも常に、今後も」と指示し、共通基盤へのルール整備を明示依頼。既存・新規・今後の全アプリと全AIの恒久ルールとしてDEVELOPMENT_APPROVAL.mdへ明文化。ローカル編集もGO前は禁止し、不具合報告・改善要望・質問への回答・仕様同意から開発許可を推定しない。即時本番規則をGO後へ限定し、新規アプリ用AGENTSにも反映。今回は文書だけを更新し、アプリの開発・ビルド・配布は行わない。
